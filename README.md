# BTC-Viewer – User Guide

User guide of the Android app **BTC-Viewer**: the Bitcoin price over its whole history with power-law fits, and the
**n-Viewer** with the growth exponent of the price over the halving cycles.

**[BTC-Viewer-Manual.pdf](BTC-Viewer-Manual.pdf)** – describes app version 0.5.59 (November 20, 2026).

The guide explains every screen and button, the three UI Feature Levels, calendar time and block time, and the rules
the app follows on its own. It does not explain the mathematics behind the models.
